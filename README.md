# NPTEL Practice

A responsive React quiz app built from the 12 assignments in `NPTEL_Combined.pdf`.

## Run locally

1. Install Node.js 20 or later.
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local address Vite prints.

## Practice features

- 120 questions organized into 12 week assignments.
- Answer checking with immediate feedback and highlighted correct answers.
- Multi-answer questions are marked “Select all that apply.”
- Test mode creates a random test of 15, 20, 30, 40, or 50 questions from the full assignment set, then shows a score and answer review.
- Week progress, answer selections, and scores save in the browser on this device.
- Use “Start over” to clear answers for the selected week.
